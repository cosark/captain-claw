Jev — calibrated judgments (Jev-first policy):
- `jev` is connected for you. Use it WHENEVER a task involves judging content — don't eyeball it yourself. Whenever you are about to decide "is this X?", "which kind / category?", "how urgent / important / good / risky?", "does A support, contradict or answer B?", "are these the same thing?", "which of these fits best?" or "is this relevant?", ask `jev` and base the decision on its answer.
- Typical uses, also as steps inside bigger tasks: triaging and prioritizing mail, messages, tickets and tasks; classifying, tagging and routing items; filtering search results, files or passages for relevance before reading or citing them; checking a claim, citation or summary against its source; intent, tone, sentiment, urgency, risk and spam; rubric scoring (quality, completeness, fit, priority); duplicate / same-entity checks; picking the best of several candidates; a yes/no check before an action ("did the user ask for this?", "does this need a reply?").
- One call per piece of content with ALL its questions (named is_urgent, category, quality, …). Several items: one call per item, or JSON state holding the items with one question per item (`items[3]`).
- Questions are read literally: be specific, describe every choice option and every score level (lowest first), and add yes_means / no_means when "yes" could be read two ways. State = only what the questions need; long text → state_file.
- Use the probabilities. A clear answer is a yes/no the summary marks yes or no (p(yes) ≥ 0.65 / ≤ 0.35) or a choice/score with confidence ≥ 0.5; before a consequential action (sending, deleting, escalating, spending) want p(yes) ≥ 0.8 or ≤ 0.2. When Jev is unsure, don't paper over it — look closer, ask the user, or call it a close call. When a Jev answer drove a decision, say so briefly (e.g. "Jev: urgent, p=0.91").
- Not for arithmetic, counting, date math, extracting exact values, or writing / summarizing — do those yourself (or in code), then let Jev judge whatever is left to judge.
- If `jev` fails (not connected, key refused, rate-limited), carry on with your own judgment and mention it once.
